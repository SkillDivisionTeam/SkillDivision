## По ролям

### Backend — материала хватает

**Писать про:** REST API, модели, аналитику, интеграцию с ботом.
**Критично до защиты:** `AllowAny`, auto-admin при логине, `correct_index` в API, нет валидации score.
**Желательно:** unit-тесты, OpenAPI или убрать из claims, CSV API или снять с UI.

### Frontend — материала хватает

**Писать про:** UX/UI, SPA, REST, визуализация (Recharts).
**Критично:** CSV-заглушка при обещании в Landing; Gemini key на клиенте.
**Желательно:** 2–3 Vitest, скрины для БКР.

### Bot — материала хватает

**Писать про:** thin client, GigaChat, solo/duel flow.
**Критично:** in-memory state (рестарт = потеря дуэлей), нет автотестов, `verify_ssl_certs=False`.
**Желательно:** pytest с mock API; раздел «ограничения MVP».

### DevOps — инфра готова, текст пишем

**Писать про:** Docker, CI/CD, Nginx, секреты, процессы команды.

## Топ-4 приоритета (2–3 недели)

1. **Backend:** permissions + убрать `correct_index` из публичного API.
2. **Каждый:** хотя бы минимальные тесты в своей зоне.
3. **CSV:** сделать или честно убрать с презентации и UI.
4. **Общая часть:** таблица «спека vs реализация» + сценарий демо.

---

## Сценарий демо (черновик, 5–7 мин)

1. **30 сек** — что такое Skill Division (IT-квизы, бот + веб).
2. **2 мин** — веб: логин → список событий → dashboard с аналитикой.
3. **2 мин** — бот: /start → квиз → лидерборд (или дуэль, если стабильно).
4. **1 мин** — инфра одной фразой: `docker compose up`, CI, один `.env`.
5. **1 мин** — честно: «MVP 1, CSV и полная безопасность — в roadmap».
